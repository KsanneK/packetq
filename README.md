# packetq 📦

> A lightweight, concurrent TCP message broker written from scratch in Go.

*Status: Work in progress (WIP). Currently laying down the core protocol and storage foundations.*

---

## What is this?
`packetq` is an experimental message broker designed to explore low-level network programming, concurrency primitives, and custom storage mechanics in Go.

## Current Roadmap
- [ ] Core TCP protocol & packet parsing
- [ ] Thread-safe data structures & storage
- [ ] Broker topics & subscriptions
- [ ] Concurrency controls & client CLI
